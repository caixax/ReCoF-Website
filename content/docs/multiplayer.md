Cry of Fear has a co-op campaign for up to 4 players, and a Manhunt mode. ReCoF players can join servers that run the [ReCoF Server](/docs/server/), and anyone can host one.

> [!IMPORTANT]
> Servers for ReCoF players need **ReCoF 0.2.3 or later**. A ReCoF server turns away the original game and older ReCoF versions with a message, unless its owner lets everyone in.

## Joining a server

Ask the server's owner for its address, for example `203.0.113.10:27015`. Then use any of these:

- **The launcher**: **Join a server**, in the menu beside **Play ReCoF**, starts ReCoF and joins the address you type. It remembers the last one.
- **The game's server list**: **Join Server** in the main menu lists ReCoF servers on the Internet and on your local network, with a box to show ReCoF servers only and a box to join an address.
- **The console**: press the console key and type `connect 203.0.113.10:27015`. The port can be left out when it is 27015.

## Good to know

- Steam must be running, and the server checks your Steam account when you join.
- Your iron sights mode and subtitle language are your own in co-op; they no longer follow the host's settings.
- When nobody is in the game, a ReCoF server waits: the map starts its music, cameras and scripts when the first player arrives.
- Leaving a co-op game and going back to the menu works normally in ReCoF; in the original game it could break the 3D menu with "Illegible server message".
