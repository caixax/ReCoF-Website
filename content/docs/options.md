There are three ways to change these:

- **In the game**: **Options** has a **ReCoF** tab, and the graphics options are on the **Graphics** tab. Each option has a help line.
- **In the launcher**: **Launch options** lists them by group, explained, and saves them for the next start.
- **In the console**: type the name and a value, for example `rc_hud_timer 1`. Options are saved with your settings, so they stay set.

An option marked "launch option" is given when the game starts (`-novid`), not in the console; the launcher sets those for you.

> [!NOTE]
> The defaults keep the game as the original plays it. The performance options are the exception: they are on, and each one draws exactly the same picture as the original way, which `0` brings back for comparison.
