Cry of Fear 1.6a, rebuilt from its source

ReCoF

The original Cry of Fear with its bugs fixed, running faster, and with co-op servers you can host yourself. A launcher installs it next to your Steam copy, which it never touches.

Install guide Download the launcher Read the docs

Play in three steps

You need Cry of Fear on Steam (it is free) and Windows 10 or 11.

Get the launcher

Download the ReCoF Launcher from its releases page: an installer, or one portable file.

Let it make a copy

It finds your Cry of Fear, copies it to a folder you choose and installs ReCoF on the copy, checking every file it downloads.

Press Play

It keeps ReCoF up to date and backs up your saves before every update. Your Steam game stays exactly as it was.

What ReCoF is

ReCoF starts from DeCoF, a complete decompilation of every Cry of Fear binary, rebuilt into source code that compiles back to the original game. ReCoF fixes and improves that source and stays the same game: same maps, same story, same speedrun tricks.

Bugs fixed

Crashes, save problems, AI and collision bugs and leaks of the original game, each one written down with how it was found and how it was fixed. The original balance is one option away.

What changes

Faster

The renderer draws the same picture with far less work: models on the graphics card, batched world and effects, lights with a shader. In the 0.2.3 beta, the heaviest maps run at 95 to 100 fps on an old i3 laptop that managed 65 to 80.

Performance options

Made with runners in mind

Every technique runners use is kept. An in-game timer, a LiveSplit autosplitter and practice commands come with it.

Host a co-op server

The ReCoF Server package runs the Cry of Fear co-op campaigns on Windows or on a Linux VPS, with your own copy of the game files.

  • Windows or Linux. One package for each, with start scripts that check the game files before they start.
  • Plugins. Metamod-R and AMX Mod X built for Cry of Fear, with cof.inc for its weapons, items and monsters.
  • Waits for players. With nobody in the game the map waits, so its music, cameras and scripts start for the first player.
  • ReCoF players only. The server turns away the original game, unless you let everyone in.
